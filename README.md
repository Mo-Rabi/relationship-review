# Relationship Review — خريطة التجربة

An Arabic, right-to-left interactive review with 14 topics, a conversation timeline, and 12 criteria for future relationship decisions.

Open the GitHub Pages website to explore it. The site is a standalone static page with no build step.

## Publishing

GitHub Pages publishes `index.html` from the repository's default branch at the root. `.nojekyll` disables Jekyll processing.

## Scope

The content distinguishes reported experiences, interpretations, unresolved questions, and practical lessons. It is not a clinical diagnosis or a determination of legal rights.
